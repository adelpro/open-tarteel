# Open Tarteel SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Open Tarteel crawlable and indexable in Arabic, English, and German, with real server-rendered content, canonical URLs, reciprocal `hreflang`, structured data, a clean sitemap, and tests that stop the SEO from regressing.

**Architecture:** Keep the Next.js App Router. Arabic stays at bare paths (`/`, `/about`, `/reciter/...`); English and German live under `/en` and `/de` via a middleware rewrite, so the existing route tree is preserved. Server components render the words and metadata; client components keep the player. One route/SEO table owns paths, indexability, sitemap inclusion, and locale prefixing. This is the Next.js equivalent of open-tilawa's prerender + route-table + sitemap work; it does not need a prerender script because Next already writes HTML.

**Tech Stack:** Next.js App Router, React 19, `react-intl`, `next/font`, Vitest, Playwright, TypeScript.

**Spec:** `docs/superpowers/specs/2026-11-09-seo-design.md`

## Global Constraints

- Arabic is the default and `x-default`; bare paths are Arabic. English is `/en/...`, German is `/de/...`.
- Every indexable page has one canonical, one unique title, one description, one visible H1, and a 1200×630 OG image.
- `hreflang` is reciprocal across `ar`, `en`, `de`, and `x-default`; no `hreflang` on canonicalised twins.
- `sitemap.xml` lists only indexable URLs; a noindex URL must never appear.
- Preview and branch deploys serve `X-Robots-Tag: noindex, nofollow` and advertise no sitemap.
- JSON-LD escapes `<` as `\u003c`.
- Do not add a runtime dependency unless a task names it.
- Run `npx tsc --noemit`, `npx eslint <changed files> --max-warnings=0`, and `npx vitest --run` before each commit.

## Review Focus

- A reciter id with multiple moshafs must render one page, not duplicate content or highlight the wrong row.
- An unknown reciter id must be a real 404, not a 200 with an error card.
- A page reached at `/en/...` must keep English when the user clicks an internal link; it must not silently fall back to Arabic.
- A locale twin must not be listed twice in the sitemap or claim a canonical that points elsewhere.
- A page with no meaningful content (settings, offline, 404, design-preview) must be noindex and absent from the sitemap.
